# Analisis de Datos DF Heroes
 En este repositorio hay un cuaderno de python en el cual se trabaja con un dataset de datos sobre personajes de cómics.

 Se realizan gráficas y se hace un trabajo exploratorio para responder a varias de las preguntas que están en el cuaderno.

 ## Librerías usadas:
 - Pandas
 - Numpy
 - Scipy
 - Seaborn
 - Matplotlib
